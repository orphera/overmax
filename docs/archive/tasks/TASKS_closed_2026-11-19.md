## 남겨 두는 메모

- **10.1의 구조적 약점**: `(score, rate) = (None, None)`이 `Unplayed`로 처리되어 "읽기 실패"와 "기록 없음"이 구분되지 않는다 (`play_state.rs` `process_rate_detection`). 실플레이에서 기록이 있는 패턴이 선곡 화면 `Rate: 0.00%`로 확정되는 사례가 보이면 이 지점부터 다시 본다. 후보였던 방어책: 삭제 조건 강화(미플레이 지속 시간) / 독립 샘플 검증.
- **10.1 관련 재시도 정책**: `try_handle_verified_play` / `RecordCommit::Failed`로 반환값 의미는 분리됐지만(11.3), 실패 시 재시도 정책은 정하지 않은 채로 닫는다.
- **9.1 재개 시 원칙**: 표시 전용 매핑(`song_id → {en, ja}`), 미등록 곡은 원본 폴백, V-Archive 등 외부 연동은 원본(한국어) 곡명 유지.
- **12.5 스크린샷 버튼**: 원래 6.1 단축키와 연결할 계획이었다. 6.1을 닫았으므로 단축키 없이 검토한다.
